The clean paper repository is prepared at
<https://github.com/ZackaryLoevseth/erdos-64-excess-degree-bounds>. Its exact
standard-library replay checks 343,980 admissible integer tuples, 33,866
labeled auxiliary graphs, 281,197 exact branch-cycle lifts, four unit tests,
and six deliberate mutations, with byte-for-byte agreement between two
implementation-distinct checkers. The repository becomes the executable
reproducibility home only after coordinated GitHub activation and anonymous
validation.

The written mathematical argument is the proof. The finite replay is bounded
falsification and regression evidence; it does not prove the global
Erdős–Gyárfás conjecture. No two-port theorem, TP4–20, CE22–26, absolute
priority, or external-review claim is imported. The mixed-rights private
prepublication archive remains excluded, and this mirror grants no reuse
license.
