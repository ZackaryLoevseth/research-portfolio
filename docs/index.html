Finite common-correction criterion

A single correction Δ is valid for every possible state x in a retained information cell Xz exactly when every required edit is permitted throughout that cell.

∃ Δ: Me(x) ⊆ Δ ⊆ Ue(x), ∀ x ∈ Xz⇔ ⋃x ∈ Xz Me(x) ⊆ ⋂x ∈ Xz Ue(x).

M specifies required edits; U specifies permitted edits; e is the observed event. Allowed patches are the complete interval between M and U, and edit atoms are mutually compatible. The cell is nonempty. Under these assumptions, the union of required edits is the minimum common patch.

This elementary set criterion is a baseline formulation, not a claim of newly invented set theory.
