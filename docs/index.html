“Supported” means grounded under the example’s admitted rules. It is not an unrestricted guarantee of truth.

Inspect the rule, the computed check, and its limits

Rules: A ⇒ C; B ⇒ C; C ⇒ D. The required and permitted patch is exactly closure(before) − closure(after). The browser computes grounded closure, groups the histories by their saved symbol, and checks whether each group admits one common exact correction.

Reference patches after withdrawing A: Record 1 = ∅; Record 2 = {reopen C, reopen D}.

Retrieving the original supporting record is a legitimate way to resolve the ambiguity. It supplies additional information, with its own retrieval and verification costs. This example does not establish that structured memory beats retrieval, or that a real system can construct the records correctly.

A worked correction / From the foundations manuscript

Preserve the decision.
Not an arbitrary convention.

The stochastic repair model exposes a subtle distinction: preserving an optimal decision does not always require reproducing one particular tie-breaking policy. The synthesis makes that distinction explicit.

01 / THE DISTINCTION

Two contexts, different risks.

An artifact has impact probability ¼ in one context and ¾ in another. With miss penalty 1 and unnecessary-reopening penalty 3, the decision threshold is ¾.

02 / THE OBSTRUCTION

A tie rule demands extra memory.

A “reopen on ties” convention keeps the artifact active in the first context but reopens it in the second. Reproducing that convention requires distinguishing the contexts.

03 / THE SHARPENED CLAIM

One action is optimal in both.

Keeping the artifact active is optimal in both contexts. One retained code can preserve zero representation regret; a second code would preserve the convention, not reduce Bayes risk.

A worked mathematical example and documented clarification—not a reconstructed personal discovery story or an empirical performance result.
