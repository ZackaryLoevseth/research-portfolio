Reopen exactly the claims that lose all grounded support.

REFERENCE RESULT / RECORD 1

Keep C and D supported.

Record A’s withdrawal. B still supports C, and C still supports D, so neither claim-status record needs reopening.

REFERENCE RESULT / RECORD 2

Reopen C and D.

A was the last supporting root. Both claim-status records need reassessment. Neither claim has thereby been proven false.

Both histories justify the same saved answer.

Withdraw A to see whether the selected memory format preserves enough information for the next decision.

“Supported” means grounded under the example’s admitted rules. It is not an unrestricted guarantee of truth.

Computed check and assumptions

Rules: A ⇒ C; B ⇒ C; C ⇒ D. The required and permitted patch is exactly closure(before) − closure(after). The browser computes grounded closure, groups the histories by their saved symbol, and checks whether each group admits one common exact correction.

Reference patches after withdrawing A: Record 1 = ∅; Record 2 = {reopen C, reopen D}.

Retrieving the original supporting record is a legitimate way to resolve the ambiguity. It supplies additional information, with its own retrieval and verification costs. This example does not establish that structured memory beats retrieval, or that a real system can construct the records correctly.
