Formal systems

Correction-sufficient state

A finite model of what a compressed state must retain to support a valid response to later evidence.

ETI finite note and reference code · forthcoming, release under review

Required changes and permitted changes.

A true state x, an observed event e and a compatible edit universe V determine the sets Me(x) ⊆ Ue(x). The controller sees an information cell rather than the full state. Its correction must work for every state still possible in that cell.

Finite common-correction criterion

A single correction Δ is valid for every possible state x in a retained information cell Xz exactly when every required edit is permitted throughout that cell.

∃ Δ: Me(x) ⊆ Δ ⊆ Ue(x), ∀ x ∈ Xz⇔ ⋃x ∈ Xz Me(x) ⊆ ⋂x ∈ Xz Ue(x).

M specifies required edits; U specifies permitted edits; e is the observed event. Allowed patches are the complete interval between M and U, and edit atoms are mutually compatible. The cell is nonempty. Under these assumptions, the union of required edits is the minimum common patch.

This elementary set criterion is a baseline formulation, not a claim of newly invented set theory.

The encoder is chosen before the event; the decoder observes the retained code and current event. A shared codebook and the complete interval of allowed patches are explicit assumptions.

One-shot coding has a precise boundary.

Connect two states when an event makes a shared correction impossible. Under the finite interval model, a code cell is feasible exactly when it is an independent set of this conflict graph. The minimum one-shot code count is its chromatic number.

This uses established graph-coloring machinery. Outside the interval model, pairwise compatibility can fail to guarantee a correction common to an entire cell. A one-shot encoding also need not admit consistent online updates.

Mathematical correctness, originality and practical benefit are separate judgments. No general superiority, scalable optimizer or empirical reliability advantage is established.

Grounded alternative support.

Independent supports can preserve a conclusion after one premise is withdrawn. Conjunctive rules require every premise; alternative rules require one grounded route. Circular support alone is insufficient. Unsupported conclusions reopen; they do not automatically become false.

The finite reference suite covers 32,768 support states: 4,096 subsets of twelve rule templates crossed with eight evidence subsets. It also records 98,304 transitions, including 49,152 removal scenarios. These are overlapping finite-corpus accounting units, not independent empirical experiments, and are not summed into a grand total.

RR-ETI and sequential maintenance.

RR-ETI studies revision decisions under partial information and explicit decision assumptions. Its cost-universal statistic and fixed-cost tied optima have different boundaries. The missing historical RR validation code remains an evidence gap; the manuscript is not represented as freshly replayed.

Maintaining a compressed state through a sequence adds an update-consistency obligation. The finite release remains a compact note; any substantive later result requires its own version and review.

Study 14 asks whether actual systems can construct and maintain the distinctions the formal model assumes, and at what cost.
